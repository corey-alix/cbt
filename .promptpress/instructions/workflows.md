# Critical Workflows

- **Development**: `npm run watch` for auto-compilation, F5 in VS Code to debug extension
- **Testing**: Create spec files in `specs/`, verify commands in palette, check status bar for "PromptPress"
- **AI Integration**: Set `promptpress.apiKey` in VS Code settings or `PROMPT_PRESS_XAI_API_KEY` env var
- **Spec Refinement**: Use `[AI-CLARIFY: question]` in specs for AI to address ambiguities
